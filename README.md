# OpenRepair

OpenRepair is an open-source repair tool designed to automatically
repair Unix-like file systems and disks.

🚧 Status:
This project is still a work in progress and not perfect yet, but I’m
actively working on it 🙂

------------------------------------------------------------------------

# Installation

To build OpenRepair, follow these steps:

1.  Run make:

        make


thats all :)
